HOW TO REPLACE THE WEBSITE PHOTOS
=================================

Just drop your own photo files into this folder (or the sub-folders below)
using the EXACT file names listed here. No code changes are needed — the site
picks them up automatically. If a file is missing, the site falls back to a
temporary photo, so nothing ever breaks.

HOME PAGE
  hero.jpeg              -> big photo at the top-right of the home page
                           (use a real Indian woman / group / training scene)
  women-feature.jpeg    -> photo in the "When a woman earns..." section

TEAM ("Our people" section)  -> in the  team/  sub-folder
  team/authority1.png ... team/authority9.png  -> the 9 team member photos

BRAND
  logo.png               -> Kusum Foundation logo (already added)
  seal.png               -> optional seal for certificates

TIPS
- Best format: JPG/JPEG. If your photo is a .jpg, just rename it to end in
  .jpeg so the name matches exactly (e.g. hero.jpg  ->  hero.jpeg).
- Best size: landscape, about 900 x 700 pixels or larger. Portrait photos also
  work but get cropped to a rectangle.
- After copying the files in, refresh the website (Ctrl+F5) to see them.
- Free real photos: search "Indian rural women", "self help group India",
  "women tailoring India" on pexels.com, unsplash.com or pixabay.com
  (all free to use), download, rename, and drop them here.
