# Kusum Foundation

A complete, production-ready website for **Kusum Foundation** — a non-profit
working since 2008 in Katesar, Saran District, Bihar on vocational training,
women empowerment, education support, and community welfare.

Built with the MERN stack: MongoDB, Express, React 18 + Vite, Node.js.
Tailwind CSS v4, Framer Motion, and Lucide React icons.

---

## Features

- Public pages: Home, About, Stories, Gallery, Join Us (Volunteer / Intern)
- Public certificate verification by registration number + QR code
- Admin dashboard with JWT auth (login / approve / reject / delete)
- Auto-generated PDF certificates (Appreciation for volunteers, Internship for interns)
- Fully responsive, mobile-first (375px → 1440px)
- Graceful image fallbacks — never shows a broken image
